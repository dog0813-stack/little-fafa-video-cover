# 小发发视频封面

直接交付可保存的高清 PNG。默认使用同字号大标题版式，沿用 assets 里的讲台和人物底图。若用户明确要换照片，先取得指定素材。

## 从文案到版式

- 给了主、副标题时逐字沿用，保留原标点。主标题默认放底部玫红大字，副标题放左上白字。用户指定上、下位置时以指定为准。只按语义断行。
- 给了整段口播稿时，提取最能代表本期的判断或问题做主标题，选一句补足语境或揭示冲突的话做副标题。保留原文立场、专名和事实。直接出图，并把采用的标题告诉用户。
- 日常出图省略 `layout`，把完整主标题按语义分一至两行写入 `main`，全标题使用同一字号。原文开头的「品牌」与后面的字一起排，逐字保留实际文案和标点。
- 复做旧稿时按用户指定选择版式。「上一版称呼单排」用 `opinion-large`，旧稿里的 `lead` 可继续使用。「原观点款」用 `opinion`，「对比款」用 `contrast`。对比款从稿子中提取两个确有对照关系的短词，中间单排一行 `vs`。
- 已定稿的字太长时先调整断行。观点款的副标题若排成两行时字偏小，可把末尾的关键词放在第三行，三行共用较大的字号。第三行放在左侧，避开手和麦克风。若脚本仍提示超出范围，请给用户一个可选缩写并待其决定。

## 出图

使用 Python 3.10 或以上、Pillow 10 或以上。显式加载优设标题黑 TTF。默认寻找 assets 或当前目录下名称含「优设标题黑」的 TTF。文件名不同或字体在其他目录时传 `--font`。没有字体时请用户从[优设发布页](https://www.uisdc.com/uisdc-first-free-font)取得，勿自动换字形。

在临时目录写 UTF-8 JSON。各字段的数组元素是肉眼可见的一行。观点款上方可排一至三行，对比款上方和两款底部均可排一至两行。对比中部可排一至三行。

```json
{"top":["没有消费者数据，","永远拿不到","大结果"],"main":["品牌别把自己","做成经销商"]}
```

```json
{"top":["没有价格体系，","卖得越多","越被动"],"main":["品牌别被","销量骗了！"]}
```

```json
{"layout":"contrast","top":["做大？","还是做小？"],"middle":["规模化内卷","vs","差异化破局"],"main":["精酿品牌的","生死局"]}
```

调用本技能目录中的 `scripts/render.py <文案.json> <完整输出路径.png> [--font <字体.ttf>]`。路径作为独立参数传入。输出放在用户指定目录或当前任务交付目录，改稿使用新版本文件名。排版程序自带原版字号、字距、描边、装饰和适配区域。

交付前把中间内容区缩到约 180 像素宽，检查默认主标题每个字同样大、两行能读清、副标题避开人脸，并逐字核对文案。放大检查玫红标题的笔画内侧，粗白描边应连贯，小字腔里不能漏出照片。导出应为 4500×8000 PNG，上下各有 1000 像素黑边。把高清原图链接给用户。
